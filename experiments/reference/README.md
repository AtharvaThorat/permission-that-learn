# Reference material

These files support historical evaluations and reproducibility. They are not the current research result summary.

- `laya-permission-v1/`: constructed training data and review provenance.
- `laya-permission-v1-compact/`: compact representations of the same rows.
- `memory-sim/`: simulated-user aggregates, curves and settings.
- `permission-memory/`: historical Laya predictions, provisional reviewed labels and aggregates.

Redundant per-seed CSV tables were removed from the public checkout; original versions remain in Git history at `46aed6a` and in the local publication archive. Summary tables are retained. Current evidence is in [the release index](../../docs/results/research-release/README.md).
