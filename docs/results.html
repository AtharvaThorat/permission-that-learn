01 / CORE RESULT

Small learning loop, measurable question reduction.

504permission actions per arm
29questions avoided by explicit grants
9questions avoided by active learning
0forbidden dispatches

Across 36 constructed sequences, explicit grants removed 17.3% of repeated questions, while contextual learning removed 5.4%. Every arm preserved the 36 holdout ALLOW/ASK/BLOCK expectations. The active learner is therefore a credible reduction mechanism, but it did not outperform explicit grants in this test.

PPT-safe framing: “The full 504-action demo completed in a 4.57-second local process, with sub-millisecond permission decisions and no forbidden dispatches.” Do not describe it as faster wall-clock inference or a universal cost reduction.

07 / LIMITATIONS

What this evidence does—and does not—show.

Shown

Scoped grant and contextual-learning behavior, holdout consistency, question reduction, revocation, and bounded CPU overhead in a deterministic construction.

Not shown

Real user utility, native AgentDojo attack success, GPU latency, independent human labels, or broad generalization.

Next validation

Frozen real-action pilots, independent human review, recurring-action studies, and matched repeated experiments on production hardware.
